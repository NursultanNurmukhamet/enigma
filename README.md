# Enigma I

Компактный тренажёр исторической Enigma I на русском языке. **Для игр и изучения истории: этот шифр не защищает настоящие секреты.**

**Открыть:** https://nursultannurmukhamet.github.io/enigma/

## Как пользоваться

1. Выберите три разных ротора из I–V **слева направо**, положения колец и исходные позиции. Отражатель — B.
2. При необходимости задайте коммутационную панель: до 10 пар, например `AV BS CG DL FU HZ IN KM OW RX`. Буква может участвовать только в одной паре; пары одинаковых букв запрещены.
3. Выберите формат. **«Точный текст»** сохраняет русский, регистр, пробелы, переносы, пунктуацию и emoji. **«A–Z / транслит»** совместим с прежними шифрами страницы.
4. В формате «Точный текст» выберите направление и нажмите явную кнопку шифрования или расшифрования. Для расшифрования вставьте весь контейнер `ENIGMA-UTF8-1:…`, используйте тот же ключ и исходные позиции. В формате A–Z результат пересчитывается автоматически. В обоих случаях машина каждый раз начинает **с исходных позиций**.
5. Ключ можно задать вручную, случайно сгенерировать или экспортировать в JSON и затем импортировать. Экспорт содержит только настройки машины, без текста. Передайте настройки получателю отдельно; в Telegram-ссылку они не включаются.

## Точный текст

Это современный транспортный слой вокруг исторической Enigma, не историческая возможность машины. Строка преобразуется в UTF-8, упаковывается с версией, длиной и CRC32, кодируется в A–Z и только затем проходит через роторы. Обратная операция сначала проверяет контейнер и лишь после этого показывает текст.

- Поддерживается весь корректный Unicode, включая `ё/Ё`, регистр, комбинируемые знаки и emoji; нормализации Unicode нет. Пустой текст тоже допустим и имеет свой непустой шифртекст.
- Предел — **10 000 байт UTF-8**, а не букв. Максимальный контейнер — **20 040 символов**. Длина проверяется до преобразования и выделения буферов декодирования. Формат строгий: не меняйте регистр и не добавляйте пробелы к контейнеру.
- Неизвестная версия, повреждение, недопустимые байты UTF-8 или неверный ключ приводят к ошибке без выдачи неподтверждённого текста. **CRC32 обнаруживает случайные ошибки, но не обеспечивает криптографическую аутентичность или защиту от подделки.** Успешная проверка не доказывает авторство.
- После изменения текста, ключа, формата или направления результат сбрасывается до нового явного действия. Так устаревший результат не попадёт в Telegram.
- Кодек сохраняет LF, CRLF и CR без изменений. Для точного сохранения исходных байтов используйте **«Загрузить .txt»** и **«Скачать .txt»**: файл читается как строгий UTF-8, включая BOM, и записывается без замены переносов. Загруженный исходник сохраняется в памяти без изменений до ручного редактирования поля.
- При обычном вводе браузер может нормализовать CR/CRLF в LF. Копирование передаёт исходную строку браузеру, но ОС или принимающее приложение могут менять окончания строк. «Обратно» использует отдельную исходную строку, а не нормализованное значение textarea.
- Старый транслит необратим: новый режим не может восстановить утраченное русское написание из прежних шифров.

Точная структура контейнера описана в [FORMAT.md](FORMAT.md).

## Алфавит и упрощения режима A–Z

- Машина шифрует только `A–Z`. Латинские строчные буквы превращаются в прописные; регистр не восстанавливается.
- Для русского нужно явно включить транслитерацию. Получатель восстановит латинскую транслитерацию, **не исходное русское написание**. Например, разные русские буквы и сочетания могут дать одинаковую запись. Точная таблица задана в `enigma.js`.
- Пробелы, переводы строк, цифры, знаки пунктуации и символы сохраняются на месте и **не двигают роторы**. Другие алфавиты, комбинируемые диакритические знаки и повреждённый Unicode отклоняются; селекторы представления emoji FE0E/FE0F разрешены. Сохранённые разделители раскрывают структуру сообщения.
- Это удобства интерфейса: физическая Enigma принимала отдельные буквы и не сохраняла пунктуацию. Мы не воспроизводим историческую процедуру передачи индикаторов, ежедневные таблицы ключей или группировку радиограмм.
- До 10 000 символов во входном поле и после транслитерации. Если транслитерация увеличивает сообщение сверх лимита, интерфейс просит сократить его. Для Telegram действует дополнительное ограничение длины URL, указанное в интерфейсе. Длинный результат можно скопировать.

## Что реализовано в машине

Исторические проводки роторов I–V, отражатель B, кольца A–Z (соответствуют 01–26), начальные позиции A–Z, симметричная коммутационная панель. Правый ротор шагает перед каждой буквой. Перенос по вырезам учитывает двойной шаг среднего ротора. Положение выреза определяется видимой буквой на кольце, поэтому изменение Ringstellung не перемещает буквенную позицию переноса.

## Telegram и данные

Кнопка создаёт официальный адрес `https://t.me/share/url?url=…&text=…`: `url` — фиксированная публичная ссылка сайта без параметров, `text` — только текущий шифртекст. Telegram открывается лишь по нажатию. Пользователь сам выбирает чат и подтверждает отправку. В режиме расшифрования кнопка отключена, чтобы не отправить открытый результат по ошибке.

Приложение работает локально в браузере: нет бота, сервера приложения, токенов, аналитики, сторонних библиотек или сетевых запросов при вводе. Сообщения и настройки не пишутся в cookies, localStorage, sessionStorage, IndexedDB или URL. После перезагрузки сообщения очищаются. Скопированный текст и вручную экспортированный файл остаются под контролем пользователя. GitHub Pages обслуживает статические файлы; переход в Telegram — отдельное явное действие.

## Запуск и проверки

Нужен Node.js 20+ только для локального сервера и тестов. Установка зависимостей и сборка не требуются.

```sh
node --test tests/enigma.test.mjs tests/exact-text.test.mjs
node scripts/serve.mjs
```

Откройте `http://127.0.0.1:4173`. Используйте HTTP-сервер: ES-модули могут не работать при открытии HTML через `file://`.

Контрольные значения для I–II–III, колец AAA, позиций AAA и пустой панели:

| Вход | Выход |
| --- | --- |
| `AAAAA` | `BDZGO` |
| `HELLOWORLD` | `ILBDAAMTAZ` |

Двойной шаг при I–II–III: `ADU → ADV → AEW → BFX`. Тесты также проверяют неединичные кольца, панель, обратимость, каждый вариант роторов, валидацию, транслитерацию и состав Telegram URL.

Независимый пример Py-Enigma: роторы II–IV–V, кольца BUL, отражатель B, панель `AV BS CG DL FU HZ IN KM OW RX`, старт WXC дают `BLA → KCH`; старт BLA даёт `THEXRUSSIANSXAREXCOMINGX → NIBLFMYMLLUFWCASCSSNVHAZ`. Он проверяет кольца и панель относительно опубликованного результата, а не только обратимость.

Браузерные проверки находятся в `tests/browser.mjs` (прежний режим) и `tests/exact-browser.mjs` (точный текст). Они используют уже установленный Playwright и браузер; в приложении этих зависимостей нет. Настройте `PLAYWRIGHT_MODULE` и при необходимости `BROWSER_EXECUTABLE`, запустите локальный сервер, затем оба скрипта через `node`. Telegram проверяется с перехваченным открытием окна: тесты ничего не отправляют.

## Публикация

GitHub Pages публикует корень ветки `main`; `.nojekyll` отключает обработку Jekyll. Нет собственного домена, секретов или платных сервисов. После изменения файлов запустите тесты, отправьте коммит в `main` и дождитесь успешного workflow **pages build and deployment**. Его `head_sha` должен совпадать с отправленным коммитом. Затем проверьте HTTPS-сайт и содержимое опубликованных JS/CSS.
