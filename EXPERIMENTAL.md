# Экспериментальная машина 3–30 роторов

Это самостоятельный учебный эксперимент, **не историческая Enigma I** и не современная криптозащита. Классический алгоритм и формат ключа не меняются.

## Проводки и настройки

От 3 до 30 роторов перечислены слева направо: левый — самый медленный. Проводка каждого ротора — отдельная перестановка `ABCDEFGHIJKLMNOPQRSTUVWXYZ`, где каждая буква встречается ровно один раз. Одинаковые проводки, неверная длина, неизвестные поля или лишние смещения отклоняются.

У каждого ротора только `ring` (кольцо A–Z) и `position` (исходная буква A–Z). Электрическое смещение — `position − ring`. Изменение кольца меняет проводку относительно окна; никаких нескольких эквивалентных «колец» на одном роторе нет.

Случайный ключ использует `crypto.getRandomValues`, выбор с отбрасыванием смещения распределения и перестановку Fisher–Yates. Проводки, кольца, старты и десять пар панели записываются в ключ. Это случайность генератора браузера, не обещание стойкости самой машины.

## Шаг odometer-v1

Перед каждой буквой A–Z правый ротор увеличивается на одну позицию. Если он переходит Z → A, увеличивается соседний слева; перенос продолжается только при очередном Z → A. Например, для трёх окон: `AAZ → ABA`, `AZZ → BAA`, `ZZZ → AAA`.

Кольца не меняют точку переноса. Исторических вырезов и двойного шага здесь нет. В коротком сообщении дальние левые роторы могут вообще не сменить позицию — так устроено выбранное правило. Начальные позиции заново копируются из ключа при каждой операции.

## Путь сигнала и обратимость

Панель → роторы справа налево → фиксированный отражатель B → обратные проводки слева направо → панель. Обратная перестановка строится из каждой проверенной проводки. Отражатель и панель — симметричные перестановки, поэтому с одинаковым ключом и одинаковым сбросом позиций преобразование обратимо.

В интерфейсе экспериментальная машина принимает только [точный UTF-8 формат](FORMAT.md). Благодаря этому и русский текст, и версия машины восстанавливаются однозначно; сообщения классической и экспериментальной машины не смешиваются.

## Полный ключ версии 1

```json
{
  "format": "enigma-experimental",
  "version": 1,
  "settings": {
    "rotors": [
      { "wiring": "EKMFLGDQVZNTOWYHXUSPAIBRCJ", "ring": "A", "position": "A" },
      { "wiring": "AJDKSIRUXBLHWTMCQGZNPYFVOE", "ring": "B", "position": "C" },
      { "wiring": "BDFHJLCPRTXVZNYEIWGAKMUSQO", "ring": "D", "position": "E" }
    ],
    "reflector": "B",
    "stepping": "odometer-v1",
    "plugboard": "AV BS"
  }
}
```

Пример содержит три знакомые перестановки для читаемости, но шаг всё равно экспериментальный. Генератор создаёт новые перестановки. Количество определяется длиной `rotors`, от 3 до 30; отдельного противоречащего ей поля количества нет. Каждая буква панели может входить только в одну пару, максимум десять пар.

Импорт ограничен 16 КиБ до JSON-разбора, проверяет формат/версию, точный набор полей, количество, все перестановки, кольца, старты, отражатель и шаг. Ключ экспортируется полностью и не содержит сообщений. JSON классической машины `enigma-i` версии 1 продолжает открываться в классическом режиме.

## Ограничения выполнения

Точный исходник — до 10 000 байт UTF-8, внутренний буквенный поток — до 20 026 знаков, полный экспериментальный контейнер — до 20 042. Массивы роторов и строки ограничиваются до преобразований. UI отправляет ограниченную задачу локальному Web Worker; результат применяется только если текст, направление, машина и настройки не изменились. Работа Worker не отправляет данные по сети.

Telegram получает только контейнер и публичную ссылку. Ни проводки, ни настройки колец/стартов, ни исходный текст в ссылку не включаются.
